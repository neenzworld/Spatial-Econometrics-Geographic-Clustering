1 Theoretical Foundations & Methodological Overview

Standard Ordinary Least Squares (OLS) regression relies on the fundamental assumption that observational units are independent and identically distributed (\(e_i \sim \text{i.i.d.}\)). In international relations, comparative political economy, and global public health, this assumption of independence rarely holds true. Observational units do not exist in geographic isolation; rather, they interact across administrative boundaries through physical proximity, bilateral trade flows, migration channels, shared ecosystems, and policy contagion.

As Waldo Tobler articulated in his First Law of Geography: “Everything is related to everything else, but near things are more related than distant things.”

When analyzing cross-sectional public health indicators such as national life expectancy, ignoring spatial dependence introduces three major theoretical and econometric vulnerabilities:

  1. Spatial Autocorrelation: Unobserved exogenous shocks (e.g., epidemic outbreaks, climate shocks, regional conflicts) spill across national borders, causing regression residuals to cluster geographically.

  2. Standard Error Bias: Treating spatially dependent nations as independent overestimates the effective sample size (N), suppressing standard errors and inflating t-statistics.

  3. Substantive Misspecification: Ignoring neighborhood context fails to capture how policy interventions or health dynamics in adjacent states directly impact domestic outcomes.

1.1 Learning Objectives

By completing this analytical workbook, you will develop competence in:

  • Executing spatial joins between cross-sectional attribute data and vector boundary polygons using sf and rnaturalearth.
  • Constructing spatial neighbor linkages and row-standardized spatial weight matrices (W) using spdep.
  • Calculating spatial lag variables (Wy) to systematically quantify neighborhood context effects.
  • Running Global Moran’s I hypothesis tests to evaluate global spatial autocorrelation.
  • Deriving and mapping Local Indicators of Spatial Association (LISA) to detect statistically significant health hotspots, coldspots, and spatial outliers.

4 Module 3: Spatial Weight Matrices (W) & Spatial Lag Construction

To quantify spatial dependencies, we define neighbor linkages using a Queen Contiguity Matrix (units sharing a boundary edge or vertex) and apply Row Standardization (style = "W").

The spatial lag (\(Wy_i\)) computes the weighted average life expectancy of nation \(i\)’s immediate geographic neighbors:

\[ \text{Spatial Lag}_i = \sum_{j=1}^{N} w_{ij} y_j \quad \text{where} \quad \sum_{j=1}^{N} w_{ij} = 1 \]

Code 
# Spatial Weight Matrix & Spatial Lag Construction
neighbors_list <- poly2nb(spatial_df, queen = TRUE)

if this seems unexpected, try increasing the snap argument.
Warning in poly2nb(spatial_df, queen = TRUE): neighbour object has 74 sub-graphs;
if this sub-graph count seems unexpected, try increasing the snap argument.
Code 
spatial_weights <- nb2listw(neighbors_list, style = "W", zero.policy = TRUE)

spatial_df$spatial_lag_life_exp <- lag.listw(spatial_weights, spatial_df$life_exp, zero.policy = TRUE)

spatial_df <- spatial_df %>%
  mutate(
    scale_life_exp = scale(life_exp)[,1],
    scale_lag_life_exp = scale(spatial_lag_life_exp)[,1]
  )

5.2 Local Indicators of Spatial Association (LISA)

While Global Moran’s I provides a single index for the entire globe, Local Indicators of Spatial Association (LISA) identify localized spatial clusters:

  • High-High (Hotspot): High life expectancy nation surrounded by high life expectancy neighbors.
  • Low-Low (Coldspot): Low life expectancy nation surrounded by low life expectancy neighbors.
  • Low-High / High-Low (Spatial Outliers): Nations whose outcomes significantly deviate from their surroundings.
Code 
lisa_results <- localmoran(spatial_df$life_exp, listw = spatial_weights, zero.policy = TRUE)

spatial_df <- spatial_df %>%
  mutate(
    local_moran_i = lisa_results[, "Ii"],
    lisa_p_value  = lisa_results[, "Pr(z != E(Ii))"],
    quadrant = case_when(
      scale_life_exp > 0 & scale_lag_life_exp > 0 ~ "High-High",
      scale_life_exp < 0 & scale_lag_life_exp < 0 ~ "Low-Low",
      scale_life_exp < 0 & scale_lag_life_exp > 0 ~ "Low-High",
      scale_life_exp > 0 & scale_lag_life_exp < 0 ~ "High-Low",
      TRUE ~ "Not Significant"
    ),
    cluster_category = if_else(lisa_p_value < 0.05, quadrant, "Not Significant")
  )

## Module 3: Spatial Weight Matrices (W) & Spatial Lag Construction

To quantify spatial dependencies, we define neighbor linkages using a **Queen Contiguity Matrix** (units sharing a boundary edge or vertex) and apply **Row Standardization** (`style = "W"`).

The spatial lag ($Wy_i$) computes the weighted average life expectancy of nation $i$'s immediate geographic neighbors:

$$
\text{Spatial Lag}_i = \sum_{j=1}^{N} w_{ij} y_j \quad \text{where} \quad \sum_{j=1}^{N} w_{ij} = 1
$$

```{r}
# Spatial Weight Matrix & Spatial Lag Construction
neighbors_list <- poly2nb(spatial_df, queen = TRUE)
spatial_weights <- nb2listw(neighbors_list, style = "W", zero.policy = TRUE)

spatial_df$spatial_lag_life_exp <- lag.listw(spatial_weights, spatial_df$life_exp, zero.policy = TRUE)

spatial_df <- spatial_df %>%
  mutate(
    scale_life_exp = scale(life_exp)[,1],
    scale_lag_life_exp = scale(spatial_lag_life_exp)[,1]
  )
```

### Global Moran's Scatterplot

Plotting a country's standardized life expectancy ($Zy_i$) against its neighborhood's standardized spatial lag ($ZWy_i$) yields a **Moran Scatterplot**. The slope of the regression trendline corresponds directly to the Global Moran's I coefficient.


## Module 4: Autocorrelation Testing & LISA Diagnostics

### Global Moran's I Test

We execute a formal Global Moran's I hypothesis test to determine whether global health metrics display statistically significant spatial clustering ($I > 0$), dispersion ($I < 0$), or randomness ($I \approx 0$).

```{r}
moran_global <- moran.test(spatial_df$life_exp, listw = spatial_weights, zero.policy = TRUE)
print(moran_global)
```

### Local Indicators of Spatial Association (LISA)

While Global Moran's I provides a single index for the entire globe, Local Indicators of Spatial Association (LISA) identify localized spatial clusters:

- **High-High (Hotspot)**: High life expectancy nation surrounded by high life expectancy neighbors.
- **Low-Low (Coldspot)**: Low life expectancy nation surrounded by low life expectancy neighbors.
- **Low-High / High-Low (Spatial Outliers)**: Nations whose outcomes significantly deviate from their surroundings.

```{r}
lisa_results <- localmoran(spatial_df$life_exp, listw = spatial_weights, zero.policy = TRUE)

spatial_df <- spatial_df %>%
  mutate(
    local_moran_i = lisa_results[, "Ii"],
    lisa_p_value  = lisa_results[, "Pr(z != E(Ii))"],
    quadrant = case_when(
      scale_life_exp > 0 & scale_lag_life_exp > 0 ~ "High-High",
      scale_life_exp < 0 & scale_lag_life_exp < 0 ~ "Low-Low",
      scale_life_exp < 0 & scale_lag_life_exp > 0 ~ "Low-High",
      scale_life_exp > 0 & scale_lag_life_exp < 0 ~ "High-Low",
      TRUE ~ "Not Significant"
    ),
    cluster_category = if_else(lisa_p_value < 0.05, quadrant, "Not Significant")
  )
```
